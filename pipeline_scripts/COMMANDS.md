# Commands

Everything in `pipeline_scripts/`, generated from `commands.py`.
Do not edit this file by hand: edit `SECTIONS` in `commands.py` and run
`python3 commands.py --md`.

Every command below is run from this folder:

```
cd ~/Desktop/"job account "/SeekSpider-main/pipeline_scripts
```

The folder name ends in a real space, which is why it is quoted.

## Every Day

The two you actually run.

**`python3 refresh.py`**

the whole pipeline: sync, scrape, check closed, site, deploy, carousels

**`python3 dashboard.py`**

open the dashboard and see what is due

## Posting

Nothing here posts without asking you first.

**`python3 publish_to_instagram.py`**

post whatever is due today

**`python3 publish_to_instagram.py technology-data-ai-part1`**

post one carousel by name

**`python3 publish_to_instagram.py --dry-run`**

go through the whole thing but publish nothing

**`python3 publish_to_instagram.py --schedule`**

what goes out on which day

**`python3 preview.py`**

look at every queued carousel as real slides before it goes out

**`python3 publish_reel.py ~/Desktop/'job account '/'Claude outputs'/berry_ad_reel.mp4`**

post one video as a reel (caption goes in a .txt of the same name)

## What Is Actually On Instagram

The local files only know about posts that went out through the publisher. Post from your phone and they drift. This is the fix.

**`python3 ig_sync.py --list`**

the last posts on the account, straight from Instagram

**`python3 ig_sync.py`**

file anything you posted from your phone: history, used listings, queue

**`python3 ig_sync.py --dry-run`**

show what it would change, change nothing

## The Website

build writes the file, deploy puts it live. They are separate on purpose, so you can look at it before the world does.

**`python3 build_site.py`**

rebuild berry_internships.html from the scraped listings

**`python3 deploy_site.py --check`**

what is live vs what is on your disk

**`python3 deploy_site.py`**

push the file live to internberry.netlify.app

**`python3 deploy_site.py --site-id`**

print the Netlify site id

## The Carousels

**`python3 build_carousels.py`**

build carousels for anything new

**`python3 build_carousels.py --rebuild`**

rebuild everything in the queue, which is what you want after a style change

**`python3 build_carousels.py --list`**

the category names

**`python3 build_carousels.py --category "tech"`**

just one category

**`python3 build_carousels.py --per-carousel 5`**

how many roles per post (1 to 9)

## Logos

A wrong logo is worse than an initials tile, so nothing here guesses without checking. Answers are saved forever.

**`python3 missing_logos.py`**

which employers still have no logo, most common first

**`python3 find_logos.py`**

go and find domains for the ones that are missing

**`python3 find_logos.py --category commerce`**

just that category

**`python3 find_logos.py --accept "Arup"`**

yes, that candidate is them

**`python3 find_logos.py --set "ADP Consulting" adpconsulting.com`**

no, it is this one instead

**`python3 find_logos.py --reject "Nine"`**

leave it as an initials tile and stop asking

## Background Photos

Unsplash only. Photos off Google Images are not safe to post.

**`python3 more_backgrounds.py`**

pull fresh bright photos into background pics/

**`python3 more_backgrounds.py "sunlit cafe laptop"`**

search for something specific

**`python3 more_backgrounds.py --list`**

what you already have

## When Something Looks Wrong

**`python3 check_live.py`**

ask Seek which listings have actually closed

**`python3 refresh.py --fast`**

skip the slow scrapers

**`python3 refresh.py --no-check`**

skip the closed-listing check

**`python3 commands.py`**

this list
